# Texture credits

- **Trim base color** (`floors/wood-base.png`): `Wood_Base_01` basecolor from the **Materials_Wood_02** pack (downscaled from its original 4K JPEG to a 512px PNG for web use). Used with the asset owner's confirmation that they hold a valid license for it.
- **Floor base color** (`floors/floor-wood-light.png`): the same `wood-base.png` above, lightened and desaturated (brightness/saturation adjustment, not a different photo) since the original read as too dark and richly saturated once tiled across a whole room's floor.
- **Trim normal map** (`floors/wood-normal.png`): `Wood_Base_01_normalogl.jpg` (OpenGL-convention normal map) from the same Materials_Wood_02 pack, downscaled from 4K to 1024px PNG.
- **Trim roughness map** (`floors/wood-roughness.png`): `Wood_Base_01_roughness.jpg` from the same pack, downscaled from 4K to 1024px PNG.
- **Floor plank seams** (`floors/floor-planks-bump.png`): not a photo -- a procedurally generated grayscale height field (flat gray field with darker recessed seam lines and staggered end-joints), built with `sharp` from an inline SVG. The photographed wood texture above is one continuous tileable surface with no board divisions baked in; this is the source for the floor's plank seams.
- **Floor normal map** (`floors/floor-combined-normal.png`): `wood-normal.png` above (the wood's own real grain) and a normal map converted from `floor-planks-bump.png` (via the same Sobel height-to-normal technique as the wall normal map below) blended together into one texture with a UDN normal blend. Baked into a single file rather than kept as two separate maps because MeshStandardMaterial only ever applies one of normalMap/bumpMap when both are set on a material (normalMap wins, bumpMap is silently ignored) -- there's no way to layer a second relief effect on top of an existing normalMap without combining them into one map first.
- **Walls** (`walls/stucco-white.png`): base color map, cropped from `white_stucco_diff_4k.jpg` in Poly Haven's **White Stucco** material (CC0), from `white_stucco_4k.blend.zip`.
- **Wall normal map** (`walls/stucco-normal.png`): generated from the same White Stucco material's own `white_stucco_disp_4k.png` displacement/height map (real scanned surface data, not synthetic) via a Sobel height-to-normal conversion, downscaled to 1024px. Poly Haven ships the material's true normal map as `white_stucco_nor_gl_4k.exr`, but the installed image tooling here (macOS `sips`, `sharp`/libvips) can't decode that EXR's compression, so the normal map was derived from the displacement PNG instead rather than skipped.
